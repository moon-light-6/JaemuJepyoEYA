DART XML 문서 검증 뷰어

*_xml_documents.json을 선택해 제목·XPath·본문을 읽기 좋게 확인합니다. 파일은 브라우저 밖으로 전송되지 않습니다.

선택할 파일 위치 — XML 청킹 준비를 마치면 아래 경로에 *_xml_documents.json 파일이 생성됩니다. 예: 삼성전자 연결은 data/processed/xml/dart/00126380/2025/consolidated/20260310002820_xml_documents.json입니다.

파일이 없을 때: 수집·생성 방법 자세히 보기

1. 현재 파일 경로 규칙

data/processed/xml/dart/{corp_code}/{fiscal_year}/{statement_scope}/{rcept_no}_xml_documents.json
  • corp_code: DART 고유번호. 예: 삼성전자 00126380
  • fiscal_year: 사업연도. 예: 2025
  • statement_scope: 연결은 consolidated, 별도는 separate
  • rcept_no: DART 접수번호

2. 원본 XML ZIP이 없다면 먼저 수집

python scripts/collect.py \\ --corp-code {corp_code} \\ --fiscal-year {fiscal_year}

줄을 나눌 때는 각 줄 끝에 \를 하나만 쓰고, 그 뒤에 공백 없이 Enter를 누릅니다. 한 줄로 실행하려면 \를 모두 빼고 명령어를 이어 씁니다.

수집이 끝나면 원본은 data/raw/dart/{corp_code}/{fiscal_year}/{rcept_no}.zip에 생깁니다. 출력된 접수번호를 다음 명령의 {rcept_no} 자리에 넣습니다.

3. XML 문서 JSON만 생성

python scripts/run_pipeline_xml.py \\ --company "회사명" \\ --corp-code {corp_code} \\ --fiscal-year {fiscal_year} \\ --rcept-no {rcept_no} \\ --statement-scope consolidated \\ --prepare-only

별도 재무제표를 만들 때는 마지막 기준을 --statement-scope separate로 바꿉니다. --prepare-only는 XML 문서와 청크까지만 만들며, 평가셋·검색 평가는 실행하지 않습니다.

예전 경로인 data/processed/dart/...가 아니라, 현재는 원본 형식을 구분하기 위해 data/processed/xml/dart/... 아래를 사용합니다.

JSON 파일을 선택하세요.
사용 방법
1. 위에서 20260310002820_xml_documents.json처럼 _xml_documents.json으로 끝나는 파일을 선택합니다.
2. 평가셋의 source_xpath, 질문의 계정명 또는 주석 제목으로 검색합니다.
3. 왼쪽 결과를 클릭해 제목·구간·XPath·원문 텍스트를 대조합니다.

이 뷰어는 읽기 전용입니다. draft → verified 변경은 평가셋 JSON에서 별도로 수행합니다.
